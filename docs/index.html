Aktien-Analyse

Die Seite wird gebaut. Die Daten dahinter laufen bereits.

Zweimal werktags analysiert ein Lauf auf GitHub Actions 532 US-Titel aus elf Branchen, setzt Kursziele aus einer Messung statt aus geschätzten Faktoren und führt zwei virtuelle Vergleichsdepots — Analyse gegen Zufall. Die Ergebnisse liegen schon jetzt als JSON im Repo:

  • latest.json — die Analyse von heute
  • calibration.json — die Messlatte
  • equity.json — beide Depots und SPY
  • trades.json — jeder abgeschlossene Trade
  • weights.json — was die Lernschleife geändert hat
  • status.json — der letzte Lauf

Quelltext und Dokumentation auf GitHub

Simulation zu Lernzwecken, keine Anlageberatung. Es wird kein echtes Geld eingesetzt. Die gezeigten Zahlen stammen aus einer Rückrechnung und aus einem simulierten Depot; sie sagen nichts über künftige Kurse.
